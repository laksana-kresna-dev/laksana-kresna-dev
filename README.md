### 🧠 Engineering Philosophy

I believe good engineering is not only about writing code.

It's about **understanding the problem, choosing the right level of complexity, keeping systems maintainable, and continuously looking for opportunities to improve the way work gets done.**

One of my favorite engineering principles is simple:

```text
If I do it once       → Do it manually.
If I do it twice      → Start thinking about it.
If I do it repeatedly → Automate it.
```

I enjoy the process of going from:

```text
Problem
   ↓
Understand
   ↓
Design
   ↓
Build
   ↓
Automate
   ↓
Observe
   ↓
Improve
```
